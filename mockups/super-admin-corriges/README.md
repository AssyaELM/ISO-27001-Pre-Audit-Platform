# NormCore — Super Admin mockups

Set of high-fidelity, light UI mockups for the internal NormCore Super Admin account, refreshed for a 1366 × 768 laptop viewport.

## Scope

Included:

- Super Admin login
- Dashboard with aggregate KPIs and status visualizations
- Organizations list with search, filters and lifecycle actions
- Add Organization with only Organization Name and Primary Email
- Generated activation token and invitation success state
- Organization detail with aggregate onboarding state, access controls and internal notes
- Invitations & Tokens management
- Activity Log
- Super Admin profile and settings
- Delete / suspend / reactivate / archive confirmations
- Empty, loading, success and error states

Explicitly excluded:

- Client or organization onboarding
- Detailed assessment answers
- Evidence Room
- AI documents
- Gap analysis
- Remediation plan
- Confidential client content

## Open the prototype

Open [index.html](./index.html) and use the Prototype view selector, or open an individual named screen from [screens](./screens).

PNG exports are available in [exports](./exports) for review or presentation.

The URL parameter format is:

    index.html?screen=dashboard

Available values:

login, dashboard, organizations, add-organization, token-generated, organization-detail, invitations, activity, settings, confirmations, empty-states, feedback-states

## Visual system

- Light canvas and white surfaces
- NormCore teal accent with deep ink header
- Horizontal top navigation; no vertical sidebar
- Thin borders, restrained shadows and compact B2B SaaS spacing
- Existing NormCore mark reused from public/images/normcore-logo-symbol.png
- No decorative image assets or SVGs
- Text uses stronger ink/teal contrast and larger laptop-readable sizing
- Dashboard status visualization uses a segmented distribution bar and colored status tiles instead of a donut chart
- Login follows the existing NormCore centered authentication composition

## Mock data notes

All organization names, emails, IDs, timestamps, metrics and tokens are fictitious.
The displayed token example is 12 alphanumeric characters, generated by the system and intentionally not shown in the main organizations table.
