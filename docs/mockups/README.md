# Mockups officiels CapISO

Ce dossier contient les mockups de reference de l'application CapISO.

Ils fixent :

- la direction visuelle ;
- la densite d'information ;
- la structure desktop ;
- les styles de cartes, tableaux, formulaires et etats ;
- le style des illustrations.

Les ecrans peuvent etre ameliores, mais l'application doit conserver le meme esprit graphique.
