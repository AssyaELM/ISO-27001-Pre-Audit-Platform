# Project Overview: NormCore

## What is NormCore?

NormCore (formerly known as the CapISO prototype) is a comprehensive web platform designed to facilitate ISO 27001 pre-audits. It provides organizations with a guided pathway to assess their security posture, identify gaps, plan remediations, and automatically generate required compliance documentation.

## Goals

1. **Simplify Compliance**: Translate complex ISO 27001 requirements into actionable, understandable steps.
2. **Automate Documentation**: Leverage AI to draft heavy policy documents based on real organizational context.
3. **Centralize Evidence**: Provide an Evidence Room to collect and link proofs directly to ISO controls.
4. **Secure Multi-Tenancy**: Ensure absolute data isolation between different organizations using the platform.

## Target Audience

- Small to Medium Businesses (SMBs) preparing for ISO 27001 certification.
- Security consultants and auditors managing multiple clients.
