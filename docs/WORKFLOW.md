# Workflows

NormCore guides organizations through a structured ISO 27001 readiness workflow.

## 1. Onboarding
Initial setup capturing the organization's context (size, industry, operations) to tailor the assessment.

## 2. Assessment
An interactive questionnaire evaluating the organization against ISO 27001 Annex A controls (Organizational, People, Physical, Technological).

## 3. Gap Analysis
The system automatically compares assessment answers against the ISO standard requirements to identify compliance gaps.

## 4. Remediation Plan
For every gap identified, a remediation action is created. The organization can track progress, assign responsibilities, and set deadlines.

## 5. Evidence Room
A centralized repository to upload, link, and manage proofs of compliance (policies, logs, screenshots), linking them directly to controls.

## 6. AI Documents
Automated generation of mandatory ISO 27001 documentation (e.g., Information Security Policy) using the context gathered during the assessment and gap analysis phases.
