# Charte visuelle CapISO

## Direction officielle

L'interface doit respecter l'esprit graphique des mockups officiels situes dans `docs/mockups/`.

Principes :

- interface blanche et bleu nuit ;
- cartes sobres ;
- tableaux metiers lisibles ;
- navigation principalement desktop ;
- hierarchie visuelle stable entre les ecrans ;
- illustrations coherentes autour de la securite, de l'audit, des preuves et de la documentation ;
- composants coherents sur toute l'application.

## A eviter

- emojis dans l'interface ;
- illustrations decoratives sans utilite ;
- changements brusques de style entre les pages ;
- multiplication des couleurs ;
- composants visuels non coherents avec les mockups ;
- illustrations SVG inventees pour remplacer les images de reference.

## Icones et illustrations

- Utiliser une seule bibliotheque d'icones coherente.
- Les nouvelles illustrations doivent garder le style visuel existant.
- Si une nouvelle image est necessaire, la generer avec le skill imagegen, puis l'enregistrer dans le projet.
- Les illustrations doivent servir un usage clair : securite, audit, preuves, documents, perimetre, evaluation ou reporting.

## Nom dans l'interface

Tout ancien nom visible dans les mockups, comme CapSMSI, doit etre remplace par CapISO dans l'application finale.
